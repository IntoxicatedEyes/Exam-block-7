## Тема: "Исследование заболеваемости ВИЧ в Российской Федерации"

### 1. Цель проекта

Исходя из статистических данных, построить модель, прогнозирующую заболеваемость ВИЧ (на 100 тыс. населения) по регионам России (с разбивкой по годам) и оценить, насколько точно она это делает.

В данном проекте использована модель линейной регрессии.
### 2. Подцели (задачи исследования)

* Загрузить и очистить данные (убрала РФ и федеральные округа)
* Подготовить признаки (применить метод One-Hot Encoding, для получения более точных данных) 
* Разделить данные (Train/test)
* Обучить модель (LinearRegression)
* Оценить качество 

### 3. Датасет

Ссылка на источник: <https://data.rcsi.science/data-catalog/datasets/157/>
Сам датасет: "analytics_result.csv"

### 4. Целевая переменная

Целевая переменная: заболеваемость ВИЧ - "hiv_firstdiagnosis_100k"

#### 5. Итоговые результаты

На выходе модель дала следующие результаты: {'rows': 680, 'features': 94, 'MAE': 6.29, 'RMSE': 8.83, 'R2': 0.956}, где:
* 'rows': 680 - количество строк в данных после очистки.
* 'features': 94 - количество признаков (колонок), которые использует модель. До применения One-Hot признаков было 10, после - 94.
* 'MAE': 6.29 - средняя абсолютная ошибка (модель в среднем ошибается на ±6.29 на 100 тыс. населения).
* 'RMSE': 8.83 - корень из среднеквадратичной ошибки (с учётом больших промахов модель ошибается на ±8.83 на 100 тыс.).
* 'R2': 0.956 - коэффициент детерминации (модель объясняет 95.6% дисперсии заболеваемости ВИЧ).
